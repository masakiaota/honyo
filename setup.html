WELCOME TO HONYO

Copy text. Get a translation.

Enable the shortcut and choose how to translate.

1. Enable Accessibility

Checking…

Honyo uses this permission to detect double-copy shortcuts and display translations near selected text.

  1. Open macOS Accessibility settings using the button below.
  2. Enable Honyo in the list.
  3. Return here. Permission status updates automatically.
App missing or permission not recognized?

If Honyo is missing, add the running app with the + button. If enabled but not recognized, turn it off and on, then restart Honyo. After an update, you may need to remove the old entry and add the app again.

2. Choose a translation model

On Apple Silicon Macs, download an offline model in Settings with no account required. You can also sign in to ChatGPT or add an API key for cloud translation.

Grant Accessibility permission to start.

Then select text and press ⌘C → ⌘C. Reopen this screen from Setup and Permissions… in the menu bar.
